# Pets and Farm Update: "Try it for real" (for Karolis and Izabele)

The check kit tests a copy of the game in a browser with no sound, no real iPad and fake friends. These things only people can check.
Tick a box when it feels right; write a note when it does not. Until a box is ticked, that part stays NOT VERIFIED.
Best on the real iPad (Safari, Home Screen app) and one PC, both playing together.
